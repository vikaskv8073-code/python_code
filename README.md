Python Basics: 10 Beginner Programs 🚀
This repository contains 10 basic Python programs designed to practice fundamental programming concepts such as variables, loops, conditionals, data structures (lists and dictionaries), and string manipulation.

📝 List of Programs
Here are the 10 programs included in this project:

Personal Info Printer: Uses variables to print Name, College, and Current Role.

Basic Calculator: Takes two numbers as input and performs Addition, Subtraction, Multiplication, and Division.

Even or Odd Checker: Checks if a user-inputted number is even or odd.

Largest Number Finder: Compares three numbers and finds the largest one.

Number Printer (1 to 100): Prints numbers from 1 to 100 using both a for loop and a while loop.

Factorial Calculator: Calculates the factorial of a given number.

List Operations: Creates a list of 10 numbers and demonstrates append(), remove(), sort(), and reverse() methods.

Vowel Counter: Counts the total number of vowels in a user-provided string.

Student Details Dictionary: Stores student details (Name, Age, Course) in a dictionary and prints them using a loop.

Palindrome Checker: Checks whether a given string is a palindrome (reads the same forwards and backwards).
